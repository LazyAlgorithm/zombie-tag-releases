# Zombie Tag branding

Generated with the built-in imagegen tool. Gameplay art remains the owner-supplied Synty packs. PNG masters are retained; ICO is a format conversion of the generated app icon, containing 16–256 px sizes.

- `app-icon.png`: square app/Hub icon, opaque background.
- `app-icon.ico`: Windows executable and shortcut icon.
- `logo.png`: transparent title logo.
- `hub-cover.png`: wide Hub cover; dark left space allows the Hub's title overlay.

## Final prompt set

**App icon — logo-brand:** Square app icon for Zombie Tag, a multiplayer first-person low-poly horror game about escaping a dark furnished house while zombies hunt humans. Polished, bold small-size icon: angular zombie hand reaching around a slightly open house door, small warm brass key silhouetted in doorway. Stylized low-poly graphic illustration, clean silhouette, restrained detail, navy/teal shadows, muted infected green and ivory highlights, subtle red accent. Centered, safe margins, opaque square, no OS mask, text or watermark. Recognizable at 32 px.

**Logo — logo-brand:** Production title logo, exact text “ZOMBIE TAG”, only these words, all caps. Compact bespoke block lettering, slightly distressed but readable, warm ivory ZOMBIE above muted red TAG, brass house key underline, subtle angular door behind letters. Low-poly graphic aesthetic, dark navy edging. Centered standalone wordmark, generous padding, actual transparent background, no backdrop/mockup/additional words/watermark.

**Cover — ads-marketing:** Wide 5:2 horizontal Hub artwork for Zombie Tag. Low-poly cinematic horror illustration: furnished domestic hallway, picture frames, side table with small brass key, open doorways, human with flashlight and distant zombie silhouette. Teal/navy shadows, ivory flashlight, restrained brass/red accents. Scenery centered/right, quiet dark left third for Hub title, dark bottom edge. Suspense without gore. No text, logo, watermark or HUD.
